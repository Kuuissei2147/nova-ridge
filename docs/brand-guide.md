# NOVA RIDGE ブランドガイド

## ブランドの核

NOVA RIDGE は**架空の、プレミアムで近未来的なスキーリゾート**である。
北緯64.9°、山脈の最果て。訪問者は「山に近づき、その中へ入っていく」体験をする。

キーワード:**没入感 / 上質 / 冒険 / わずかな神秘性**

## 中心概念:The Approach(接近)

サイト全体がひとつのカメラワークである。
スクロールは「ページ送り」ではなく「山への接近」。この原則を壊す機能は追加しない。

- **3Dの山が常に主役。** UIは山を覆い隠さず、透けさせるか、道を譲る
- 訪問者は観客ではなく、これから山に入る当事者

## トーン&ボイス(日本語コピー)

- **短い断定。句点で終える。**「パトロールなし。照明なし。容赦なし。」
- 読点でリズムを作る:「山脈の、最果てへ。」「未知の、中へ。」
- 誇張の形容詞よりも、事実と余白で凄みを出す
- 遊び心は一滴だけ:「雪だけが、本物です。」
