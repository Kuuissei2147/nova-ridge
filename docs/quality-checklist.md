# 品質チェックリスト

変更をリリースする前に必ず通す。**1つでも落ちたらリリースしない。**

## 1. ビルド(必須・機械的)

- [ ] `npm run build` が成功する(tsc の型チェック + vite ビルド)
- [ ] コンソールにエラー・警告が出ていない(dev サーバーで確認)
- [ ] 新しい依存パッケージを追加していない(追加した場合、理由を PR/コミットに明記)

## 2. ビジュアル(セクション別)

- [ ] **ヒーロー**:山が主役として見えている。タイトル・データ・CTAの配置崩れなし
- [ ] **Journey**:CHASE THE WHITE. → ENTER THE UNKNOWN. の転換がスクロールに同期
- [ ] **コース**:3行が1本ずつ出現。ホバーでルート発光+カメラ寄り+詳細パネル展開
- [ ] **予約**:フィールド表示・エラー表示・確認オーバーレイの一連が動く
- [ ] スキーヤーがループし、トレイルが流れている
- [ ] HMR後の見た目で判断しない(必ずリロードして確認)

## 3. インタラクション

- [ ] マウス:ホバー演出(コース名・CTA・サウンドトグル)
- [ ] キーボード:Tab で全インタラクティブ要素にフォーカスが届き、リングが見える。
      コース行はフォーカスで発動、Escape で解除。オーバーレイは Escape で閉じ、フォーカスが戻る
- [ ] タッチ:コース行タップで切替、フォーム入力、確認演出(モバイル幅で)

## 4. レスポンシブ / モバイル性能

- [ ] 375px幅で全セクション崩れなし(横スクロールが発生していない)
- [ ] モバイルで雪が450に落ちている(コード上の確認でよい)
- [ ] 新規追加した3D要素・パーティクルの数と負荷を数字で把握している

## 5. アクセシビリティ

- [ ] 新規インタラクティブ要素に適切なロール・ラベル(`aria-pressed` / `aria-expanded` 等)
- [ ] `prefers-reduced-motion: reduce` でDOMアニメーションが止まる
- [ ] 文字と背景のコントラストが極端に落ちていない(半透明背景の上のテキストに注意)

## 6. サウンド

- [ ] SOUND OFF がデフォルト。ONで風+ドローンが始まり、OFFでフェード後に suspended
- [ ] 各効果音(ホバー/クリック/予約確定)が鳴り、音量バランスが崩れていない

## 7. 回帰(壊していないこと)

- [ ] 既存の動作を**明示的な依頼なしに削除・変更していない**
- [ ] 見た目の改善と構造のリファクタが同じ変更に混ざっていない
- [ ] `docs/` の関連ドキュメント(デザイン値・パラメータ)を更新した
