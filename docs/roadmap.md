# ロードマップ

原則:**山が主役 / モバイル性能を落とさない / 依存を増やさない / 既存動作を壊さない**。
「見た目の改善」と「構造のリファクタ」は別のコミットに分ける。

## Phase 1 — MVP(完了)

ヒーロー3D / 降雪 / スクロール接近 / 見出し転換 / コース紹介(インタラクティブ)/
スキーヤー+トレイル / 架空予約+確認演出 / Web Audio 環境音・効果音 / 日本語ローカライズ

## Phase 2 — 守る(すぐやる・小粒)

- [ ] コースデータの一元化(`src/data/courses.ts` に RUNS / ルート形状 / カメラ寄りを統合)
- [ ] reduced-motion の3D対応(パララックス停止・カメラ移動の減衰強化・雪の減速)
- [ ] OGP・meta・favicon(プロシージャルSVG)の整備
- [ ] バンドル分割(three を manualChunks で分離)
- [ ] GitHub Actions で push 時に `npm run build` を自動実行(壊れpushの防止)
- [ ] WebGL 非対応環境のフォールバック文言
- [ ] サウンド設定の localStorage 記憶(再生開始は引き続きユーザー操作後)

## Phase 3 — 育てる(次の機能・優先順)

1. ✅ **オーロラと夜空の強化**(手続き的シェーダー)— 実装済み(`Aurora.tsx`)。
   山の背後 z=-56 の1枚プレーン+カスタムシェーダー。縦の光条2層+土台のグロー、
   下から緑→シアン→ブルー→パープル、最大不透明度0.35、reduced-motion で静止
2. **JP/EN 言語トグル**
   コンテンツは既に構造化済み(RUNS等)。文言を辞書化して切替。ブランドの
   「英語×日本語」構成と自然に整合。海外の閲覧者に体験を開く
3. **FIRST TRACKS — 選んだコースをカメラが滑る**
   コース選択時、既存の TubeGeometry のカーブに沿ってカメラがルートを俯瞰飛行する
   プレビュー演出。既存システム(ルート・カメラ減衰)の統合で実現。体験の目玉になる
