# プロダクトゴール

## このサイトは何か

架空のスキーリゾート NOVA RIDGE の、シネマティックなインタラクティブ 3D ランディングページ。
実在のビジネスは存在しない。**体験そのものがプロダクト**である。

## フェーズ

| フェーズ | 状態 | 内容 |
|---|---|---|
| 1. MVP | ✅ 完了 | ヒーロー / 接近演出 / コース紹介 / 架空予約 / 効果音 |
| 2. 育てる(Grow) | 現在 | 体験を深める機能追加(roadmap.md 参照) |
| 3. 守る(Protect) | 現在 | 品質・安定性の維持(quality-checklist.md / release-process.md 参照) |

## ゴール(優先順)

1. **没入感** — 訪問者が「山に入っていく」感覚を最後まで途切れさせない
2. **モバイル性能** — 追加機能でモバイルの滑らかさを犠牲にしない(これは交渉不可の制約)
3. **完成度の印象** — 細部(字間・減衰・音量)まで意図が通っていること
4. **アクセシビリティ** — キーボード操作・スクリーンリーダー・reduced-motion への配慮

## 非ゴール(やらないこと)

- 実際の予約・決済・データベース連携
- CMS・管理画面
- SEO最大化のためのコンテンツ量産
- 外部アセット(画像・フォント・音源ファイル)への依存
- 新規ライブラリの安易な追加(現在の依存 5 パッケージを基準とし、追加には明確な理由を要する)

## 成功の定義

- 初見の人が最後までスクロールし、「これは何かが違う」と感じること
- Lighthouse のパフォーマンスがモバイルで大きく劣化しないこと(3D サイトとしての範囲で)
- 機能追加後も `npm run build` が常に通り、既存動作が壊れていないこと
